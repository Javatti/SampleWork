# Robotic Projects
- The design of an extension for the mBlock graphical block-based programming software, aimed at teaching electronics concepts for the robot-building aspect, has been developed for a robotics educational institute that collaborates with numerous schools. This designed extension, which utilizes Arduino code and offers customization capabilities, has also been employed by the Iranian national robotics team in the FIRA Cup and RoboCup world championships. For more information, please refer to the [link](https://pishnam.com/education/%D8%AF%D8%A7%D9%86%D9%84%D9%88%D8%AF-%D8%A7%D9%81%D8%B2%D9%88%D9%86%D9%87-mblock-%D8%A2%D9%85%D9%88%D8%B2%D8%B4-%D9%86%D8%B5%D8%A8-%D9%88-%D8%B1%D8%A7%D9%87-%D8%A7%D9%86%D8%AF%D8%A7%D8%B2%DB%8C/) below.

- This ultrasonic distance sensor is specifically designed for children and teenagers for easy use. By simply connecting a single cable to the dedicated input port on the compatible controller board, they can conveniently view the measured distance data directly within Scratch, mBlock, and Arduino software. Additionally, it can be utilized in a variety of robotic applications, including maze-solving robots.[check this!](https://shop.pishrobot.com/product/pishrobot-module-ultrasonic-sensor/)

- Here, examples of built robots are also showcased to teach fundamental concepts of mechanics and motion mechanisms, including a forklift, a stair-climbing robot, a tank, a crane, a mixer, a racing car, and a column drill. By building each of these robots under my instruction, students learn a new core concept. With their creativity and the knowledge they have gained, they can then go on to design and build their very own custom robot.
